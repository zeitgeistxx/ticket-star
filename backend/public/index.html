Ticket Star API

NestJS service backing the Ticket Star event ticketing and attendance platform. Every route is served under the /api prefix.

Endpoint groups

  • /api/authSignup, login, Stellar wallet login, password reset
  • /api/eventsCreate, browse, update and settle events
  • /api/ticketsPurchase, scan, refund and telemetry
  • /api/walletConnect wallets, balances, trustlines
  • /api/analyticsRevenue, attendance and user metrics
  • /api/notificationsNotification feed and read state
  • /api/integrations/corsairWebhooks and audit logs

Authentication

  • Authorization: Bearer <token>Required on every non-public route
This is the API origin — there is no UI here. Open the Ticket Star web app to use the product.
